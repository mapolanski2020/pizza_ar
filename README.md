# Monte a Pizza AR

Protótipo do jogo de realidade aumentada da Forno a Lenha (pizzaria de exemplo).

- `index.html`: o jogo (abre a câmera, reconhece o adesivo e coloca a pizza 3D em cima dele)
- `targets.mind`: marcador de AR compilado a partir de `adesivo-arte.png`
- `models.glb`: ingredientes 3D (KayKit Restaurant Bits, de Kay Lousberg, licença CC0)
- `adesivos-pizza-ar.pdf`: folha A4 com 4 adesivos para imprimir

Publicado via GitHub Pages em https://mapolanski2020.github.io/pizza_ar/
